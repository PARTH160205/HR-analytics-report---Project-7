# 📊 HR Analytics Dashboard – Power BI Project

## 🔷 Project Overview
This project is an interactive **HR Analytics Dashboard** built using **Power BI** to analyze employee data and generate meaningful workforce insights.  
It enables HR teams and management to make **data-driven decisions** related to job satisfaction, salary structure, performance trends, and employee demographics.

## 🔷 Key Features

### 📌 KPI Cards
- Total Employees  
- Monthly Income  
- Total Working Years  

### 📌 Visual Analytics
- Job Satisfaction by Salary Slab  
- Salary Hike by Age Group (Waterfall Chart)  
- Performance Rating by Gender  
- Monthly Income by Marital Status  
- Detailed Employee Table

## 🔷 Business Questions Answered
- Which salary slab shows higher employee satisfaction?  
- Which age group receives maximum salary hikes?  
- Does performance vary by gender?  
- How does marital status affect income distribution?  
- Where should HR focus to improve retention and productivity?  

## 🔷 Insights Extracted
- Majority of employees fall under lower salary slabs.  
- Mid-age groups receive the highest salary increments.  
- Performance ratings show slight demographic differences.  
- Income distribution varies across marital status categories.  

## 🔷 Tech Stack
- Power BI  
- Power Query  
- DAX  
- Excel / CSV Dataset
